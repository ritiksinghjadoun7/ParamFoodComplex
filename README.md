# Param Food Complex — website concept

A redesign concept for [Param Food Complex](https://paramfood.in), a pure-veg restaurant, bakery and sweets shop in Gwalior.

This is a demo, not the official Param website.

## What's inside

- `index.html`: the whole site in one file (styles, scripts and the Param logo are embedded)
- Full menu, WhatsApp ordering cart, cake booking, catering enquiries and outlet details

## Run it

Open `index.html` in a browser. No build step needed.
